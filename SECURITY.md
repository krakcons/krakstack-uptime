# Security Policy

## Supported Versions

Security fixes are applied to the latest code on the `main` branch. Older commits and independently deployed instances are not maintained as separate release lines.

## Reporting a Vulnerability

Do not report security vulnerabilities in a public issue.

Use [GitHub's private vulnerability reporting](https://github.com/krakcons/krakstack-uptime/security/advisories/new) to send the maintainers a confidential report. Include the affected component, reproduction steps, potential impact, and any suggested mitigation.

The maintainers will acknowledge the report, investigate it, and coordinate disclosure after a fix is available. Please avoid accessing data that does not belong to you or disrupting deployed services while researching a vulnerability.
